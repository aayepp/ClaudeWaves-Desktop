# Anti-Slop Design Rule (Active)

All UI work in this project must follow authentic native desktop craft and avoid generic AI-generated design clichés:

1. **No AI-slop clutter**: no uppercase accent eyebrows above every section, no oversized padded hero banners, no nested card boxes around square album art, no harsh neon glow halos, no pill/badge spam.
2. **Tight editorial density**: stick to the 4px spacing scale; compact headers, frameless `140–148px` square artwork shelves, compact multi-column lists, restrained `216px` sidebar, and compact top search utility bar.
3. **Typography & space over boxes**: separate sections with clean spacing and crisp typographic weight/opacity contrast, not thick borders or heavy shadows.
4. **Restrained, harmonious color**: clean neutral dark/light foundations with subtle 1px hairline borders; cover-art washes stay subtle so legibility is always sharp.
5. **Every theme covered**: Dark, Light, AMOLED, Custom Accent, and Comic Pop (ink outlines only on surfaces, identical tight layout).
